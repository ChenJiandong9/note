# 微分方程 完整笔记整理

## 一、基本概念

1. **微分方程**：含有未知函数的导数（或微分）的等式。
2. **阶**：方程中未知函数导数的最高阶数。
3. **解的分类**
    - 通解：含有与方程阶数相同个数的**独立任意常数**的解。
    - 特解：确定了通解中任意常数的解（由初始条件确定）。
4. **初始条件**：用来确定通解中任意常数的条件，n阶微分方程需要n个初始条件。

---

## 二、一阶微分方程

### 1. 可分离变量的微分方程

- **标准形式**：$\boldsymbol{\frac{dy}{dx} = (f(x)) \cdot g(y)}$
- **解法**：分离变量后两边积分 步骤：移项得 $\frac{dy}{g(y)} = (f(x))dx$，两边积分 $\int \frac{dy}{g(y)} = \int (f(x))dx + C$，得到隐式通解。
- 注意：$(g(y)=0)$ 的解可能是方程的奇解，求解时不要遗漏。

### 2. 齐次微分方程

- **标准形式**：$\boldsymbol{\frac{dy}{dx} = \varphi\left( \frac{y}{x} \right)}$
- **解法**：变量替换法 令 $u = \frac{y}{x}$（即 $y = ux$），求导得 $\frac{dy}{dx} = u + x\frac{du}{dx}$，代入方程化为可分离变量型： $$u + x\frac{du}{dx} = \varphi(u) \implies \frac{du}{\varphi(u)-u} = \frac{dx}{x}$$ 积分后回代 $u=\frac{y}{x}$，得到原方程通解。

### 3. 一阶线性微分方程

分为**齐次线性**和**非齐次线性**两类：

- **一阶齐次线性方程**：$y' + P(x)y = 0$ 通解：$y = C e^{-\int P(x)dx}$（可由分离变量法推导）
- **一阶非齐次线性方程**：$\boldsymbol{y' + P(x)y = Q(x)}$
    - 通解公式： $$\boldsymbol{y = e^{-\int P(x)dx} \left( \int Q(x) \cdot e^{\int P(x)dx} dx + C \right)}$$
    - 推导方法：常数变易法（将齐次通解中的常数$C$替换为函数$(C(x))$，代入原方程求解$(C(x))$）。
    - 注意：公式中 $\int P(x)dx$ 只需取一个原函数，无需额外加常数$C$。

## 三、二阶微分方程

### （一）可降阶的二阶微分方程

核心思想：**降阶法**，将二阶方程转化为一阶方程求解。

#### 1. $y'' = (f(x))$ 型（最简型，仅含x和二阶导）

- 解法：连续积分两次 第一次：$y' = \int (f(x))dx + C_1$ 第二次：$y = \int \left( \int (f(x))dx \right) dx + C_1 x + C_2$

#### 2. $y'' = f(x, y')$ 型（不显含未知函数y）

- 解法：令 $y' = p$，则 $y'' = \frac{dp}{dx} = p'$，方程化为一阶方程： $$p' = f(x, p)$$ 解出 $p = \varphi(x, C_1)$ 后，再次积分得 $y = \int \varphi(x, C_1) dx + C_2$。

#### 3. $y'' = f(y, y')$ 型（不显含自变量x）

- 解法：令 $y' = p$，利用复合函数求导换元： $$\boldsymbol{y'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p \cdot \frac{dp}{dy}}$$
- 代入方程化为一阶方程：$p \cdot \frac{dp}{dy} = f(y, p)$
- 解出 $p = \varphi(y, C_1)$（即 $\frac{dy}{dx} = \varphi(y, C_1)$），分离变量积分得到通解。

### （二）二阶常系数线性微分方程

标准形式：$\boldsymbol{y'' + p y' + q y = (f(x))}$（$(p,q)$ 为常数）

- 当 $(f(x)) \equiv 0$ 时，为**齐次线性方程**；
- 当 $(f(x)) \not\equiv 0$ 时，为**非齐次线性方程**。

#### 1. 二阶常系数齐次线性方程：$y'' + p y' + q y = 0$

- **解法：特征方程法** 步骤1：写出特征方程：$r^2 + p r + q = 0$ 步骤2：求解特征根 $r_1, r_2$ 步骤3：根据特征根的三种情况，直接写出通解：

|特征根类型|通解形式|
|---|---|
|两个不相等实根 $r_1 \neq r_2$|$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$|
|两个相等实根 $r_1 = r_2 = r$|$y = (C_1 + C_2 x) e^{r x}$|
|一对共轭复根 $r_{1,2} = \alpha \pm i\beta$|$y = e^{\alpha x} \left( C_1 \cos\beta x + C_2 \sin\beta x \right)$|

#### 2. 二阶常系数非齐次线性方程：$y'' + p y' + q y = (f(x))$

- **解的结构**：$\boldsymbol{非齐次通解 = 对应齐次方程的通解 + 非齐次方程的一个特解}$，即 $y = Y + y^*$。
- **特解求法：待定系数法**（根据$(f(x))$的形式预设特解结构，代入方程比较系数求解）  
    常见两类$(f(x))$的特解形式： ① $(f(x)) = P_m(x) e^{\lambda x}$（$P_m(x)$为m次多项式，$\lambda$为常数） 特解形式：$\boldsymbol{y^* = x^k Q_m(x) e^{\lambda x}}$
    
    - $k$的取值：$\lambda$不是特征根时$(k=0)$；$\lambda$是单特征根时$(k=1)$；$\lambda$是重特征根时$(k=2)$；
    - $Q_m(x)$是与$P_m(x)$同次的待定多项式。
    
    ② $(f(x)) = e^{\alpha x} \left[ P_l(x) \cos\beta x + P_n(x) \sin\beta x \right]$ 特解形式：$\boldsymbol{y^* = x^k e^{\alpha x} \left[ R_m^{(1)}(x) \cos\beta x + R_m^{(2)}(x) \sin\beta x \right]}$
    - $m = \max{l,n}$，$R_m^{(1)}(x), R_m^{(2)}(x)$ 为m次待定多项式；
    - $k$的取值：$\alpha \pm i\beta$ 不是特征根时$(k=0)$；是特征根时$(k=1)$。

## 四、高阶（n阶）线性微分方程

### 1. 线性微分方程解的结构（可推广到n阶）

1. **齐次解的叠加性**：若$y_1,y_2,\dots,y_n$是n阶齐次线性方程的解，则它们的线性组合 $C_1 y_1 + C_2 y_2 + \dots + C_n y_n$ 也是方程的解。
2. **函数线性无关**：对于n个函数，若不存在不全为0的常数使得它们的线性组合恒为0，则称它们线性无关； 对两个函数的简化判断：若 $\frac{y_1}{y_2} \not\equiv$ 常数，则$y_1,y_2$线性无关。
3. **齐次通解**：n个线性无关的解（基础解系）的线性组合。
4. **非齐次通解**：对应齐次方程的通解 + 非齐次方程的一个特解。
5. **解的叠加原理**：若非齐次方程右端 $(f(x)) = f_1(x) + f_2(x)$，则特解 $y^* = y_1^* + y_2^_$（$y_1^_$对应$f_1(x)$，$y_2^*$对应$f_2(x)$）。

### 2. n阶常系数齐次线性微分方程

- 标准形式：$y^{(n)} + p_1 y^{(n-1)} + p_2 y^{(n-2)} + \dots + p_n y = 0$
- 特征方程：$r^n + p_1 r^{n-1} + p_2 r^{n-2} + \dots + p_n = 0$
- 特征根与通解的对应关系：
    - 单实根$r$ → 对应1项：$C e^{r x}$
    - k重实根$r$ → 对应k项：$(C_1 + C_2 x + \dots + C_k x^{k-1}) e^{r x}$
    - 单共轭复根$\alpha \pm i\beta$ → 对应2项：$e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$
    - k重共轭复根$\alpha \pm i\beta$ → 对应2k项： $$e^{\alpha x}\left[(C_1 + C_2 x + \dots + C_k x^{k-1})\cos\beta x + (D_1 + D_2 x + \dots + D_k x^{k-1})\sin\beta x\right]$$

## 五、核心思想与易错提醒

1. 微分方程的核心思路：**分类求解 + 降阶转化**，高阶方程降为低阶，不同类型匹配固定解法。
2. 概念区分：
    - “齐次微分方程”（一阶，指可化为$\frac{dy}{dx}=f(\frac{y}{x})$的形式）≠ “线性齐次方程”（线性方程右端为0），二者是不同分类维度的概念。
3. 可降阶方程的换元：不显含$y$型用 $y''=p'$，不显含$x$型用 $y''=p\frac{dp}{dy}$，两种换元不要混淆。
4. 待定系数法：务必先求特征根，再根据特征根与$\lambda$（或$\alpha\pm i\beta$）的关系确定$k$的取值。
